# 已验证案例：原创漫画下载站

记录日期：2026-11-07，时区 Asia/Shanghai。此页保留可复用结论，不是要求操作这个站点的指令。

## 跑通的组合

- DNSHE 免费名称，使用 `.us.ci` 后缀；实际域名已省略。
- Cloudflare Free Zone，NS 委派给该 Zone 实际分配的名称服务器。
- Cloudflare Workers Free 提供页面与同源 API，D1 保存账号、内容及小封面。
- 通过 Worker Custom Domain 自动配置解析和 HTTPS。
- 漫画文件放网盘，网站只做展示、账号、收藏、后台管理和登录后链接展示。
- 没有开启付费套餐、R2、短信、邮件或支付服务。

这些经验可迁移到作品集、资料下载站等轻量站点。它不意味着在 Worker 上运行完整 WordPress，也不代表可以承载整本漫画文件的下载流量。

## 验证到什么程度

| 项目 | 实测结果 | 不能推出的结论 |
| --- | --- | --- |
| 国内访问 | 用户确认新域名关闭代理可打开 | 所有省份、运营商和未来时间都可达 |
| 自定义域名 | NS、证书、HTTPS 和 Worker 绑定跑通 | 其他免费后缀一定兼容或永不回收 |
| 账号 | 注册、重新登录、刷新、退出及旧会话保留正常 | 可以随意重建库或替换密钥 |
| 下载保护 | 匿名/退出后 401，登录后可读取 | 已登录读者不能复制转发网盘地址 |
| 后台 | 站长上传、编辑、保存即时生效，普通账号被拒 | 隐藏前端管理入口就足够安全 |
| 免费运行 | 所有实际测试成功，没有升级套餐 | CPU、存储、请求量没有限制 |

本地共 15 项测试通过，桌面和 390 px 手机布局完成操作验证。最终封面限制为 100 KiB，某测试原图压缩为 75,016 字节。约 100 KiB 上传 CPU 抽样为 14/8/5 ms，均返回 201；一次超出标称 CPU 的成功不应成为设计预算。

案例的库容量保护设为最多 1000 本漫画、1800 张存储中的封面，属于项目自行设定的上限；不是 Cloudflare 的官方额度。未引用超过 24 小时的封面通过每日任务清理。

## 可参考的工程结构

下面是案例网站的模块划分，供实现时参考。这些业务代码属于案例工程，本技能仓库提供的是工作流程和实现经验。复用已有网站时，应先定位当前项目源码和部署说明。

- `worker/index.mjs`、`worker/auth.mjs`：注册、登录、会话、权限。
- `worker/library.mjs`：作品、封面和发布管理。
- `public/admin.js`：表单与浏览器端图片压缩。
- `migrations/`：账号、角色、作品及封面结构。
- `scripts/seed-library.mjs`：显式初始化，日常部署不执行。
- `scripts/set-admin.mjs`：只授权指定的已注册账号。
- `tests/auth.test.mjs`、`tests/admin.test.mjs`：原账号行为与后台边界验证。
- `README.md`、`DEPLOYMENT.md`：当前项目的配置与验证记录。

只有任务明确要求修改既有网站时才沿用其部署配置。新项目使用自己的账号、资源 ID、域名和凭据绑定，不把其他站点当作新项目的生产资源。

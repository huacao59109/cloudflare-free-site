# 验证与维护

## 按功能验收

只检查本次交付涉及的功能，不为静态网站添加认证测试，也不因小幅文案调整重跑整套流程。

| 涉及功能 | 验证重点 |
| --- | --- |
| 公开页面 | 主页面和深层链接可直接打开，导航有效，无意外登录前置条件 |
| 页面适配 | 桌面和窄屏布局可用，无横向溢出，菜单和表单可操作 |
| 表单 | 校验、提交、重复提交与错误提示符合设计；刷新后数据仍在 |
| 用户登录 | 注册或指定登录流程、刷新后会话、退出、过期和失败反馈 |
| 受限数据 | 匿名与退出后访问被拒，公开响应和静态文件不含私有内容 |
| 管理后台 | 普通用户无写权限，管理员保存后新请求可读到修改 |
| 上传 | 合法文件可保存，超限或不支持的文件被拒；内容类型正确 |
| 迁移 | 原账号、记录 ID、关联数据与认证配置按约定保留 |
| 正式部署 | DNS、证书、目标服务、页面与 API 在正式域名下均正常 |

涉及数据和权限变动时，优先验证真实运行时和数据库行为。生产验收只创建能明确识别和清理的测试记录，不重置用户密码、不清空生产库。区分构建通过、本地测试通过、正式域名测试通过和用户网络实测，不能互相替代。

有权限要求的外部文件链接，即使网站接口正确鉴权，已获授权的用户仍可能复制转发；若需求包含持续访问控制，需选择支持该能力的文件服务并核对成本。

## 已验证的实践与边界

记录日期：2026-11-07。以下来自一次轻量动态网站部署，不是要求新项目沿用原业务或配置。

| 实践 | 验证结果 | 适用边界 |
| --- | --- | --- |
| 免费名称 | DNSHE `.us.ci` 委派 NS 后被 Cloudflare 接管 | 需当次确认名额、后缀、续期及 Zone 接受情况 |
| 自定义域名 | Worker Custom Domain 完成 DNS 与 HTTPS 配置 | 不能只添加 CNAME 就认定绑定完成 |
| 国内访问 | 用户反馈新域名关闭代理可打开 | 仅代表当时该用户的网络 |
| 账号与后台 | 注册、登录、退出、普通用户权限及管理员保存正常 | 需要完整的服务端鉴权与持久化 |
| 小图片 | 浏览器压缩后存入 D1 的方案可运行 | 只适合少量小图；不作为通用文件存储默认方案 |
| 免费套餐 | 实测完成时未升级套餐 | 不表示请求、CPU 或容量无限 |

一次约 100 KiB 图片上传的三次 CPU 抽样为 14/8/5 ms，均返回成功；其中一次高于当时免费套餐标称 10 ms。该结果说明需要测量真实 CPU，不能用单次成功证明长期满足限额。100 KiB 是当时应用自行设定的限制，不是平台文件上限。

## 发布记录与回滚

在当前项目的部署说明中记录提交或发布版本、构建命令、资源绑定、域名、迁移编号及验收结果。密钥只记录名称和受控备份位置，不记录明文；账号专属信息不写入公共技能。

代码回滚与数据库回滚分别处理：

- 发布前确认旧版本能否读取迁移后的结构，优先采用兼容的增量迁移。
- 代码异常时按平台支持的版本回滚流程操作；回滚代码不会自动恢复数据库或外部资源。
- 恢复数据库前评估恢复点之后的新数据，必要时先导出当前状态。不要为回退页面覆盖新注册账号或新增记录。
- 在正式域名复查修复结果，保留可追溯的发布记录。

## 日常维护

- 维护域名续期日期，监测证书和自定义域名状态。
- 观察动态请求、CPU、D1 读写行数和容量；接近免费边界时先定位来源，再决定缓存、查询或存储调整。
- 数据库按变更频率备份到受控位置，并验证备份可读；源码仓库不能代替数据备份。
- 已接入后台的内容通过后台更新，代码和静态资源变化再重新部署。
- 平台规则变化时更新费用与部署说明，不把历史实测当作长期保证。

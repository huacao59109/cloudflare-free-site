# 验证与维护

## 按交付范围验收

| 范围 | 验证重点 |
| --- | --- |
| 页面 | 主页面与深层链接可打开，内容和导航正确 |
| 适配 | 桌面与手机布局可用，主要操作能完成 |
| 动态功能 | 校验、提交、错误反馈与数据保存符合需求 |
| 账号与权限（如有） | 登录、退出和会话正常，服务端权限有效 |
| 更新与迁移 | 原有数据和账号配置按约定保留 |
| 正式部署 | DNS、HTTPS、目标服务和发布版本一致 |
| 搜索收录（如需） | 原始 HTML 可读、独立地址与地图有效，站长平台的验证、提交和索引状态分别记录 |

按实际改动选择检查，不机械重跑无关项目。区分本地验证、线上验证和用户网络实测；未执行的步骤明确标注。生产验收不重置用户数据，仅清理本次明确创建的测试记录。

路由或渲染方式变化后，额外验证旧链接、深层刷新、浏览器前进后退、登录弹窗和访问统计，避免把一次页面跳转重复计数。检查 HTML 与初始化数据里是否出现私有字段；只检查最终可见界面不足以验证权限边界。

## 已验证路线

2026-11-07 的一次实际部署跑通了 DNSHE `.us.ci` 免费名称、Cloudflare Free Zone、Workers、D1 和 Worker Custom Domain。用户反馈自定义域名在其国内网络下关闭代理可打开，部署过程中未升级付费套餐。

这证明该组合在当次条件下可行，不保证所有免费名称、网络环境或未来平台规则相同。新任务仍需核对申请条件、免费额度与实际访问情况；静态站不必使用 D1。

## 发布与维护记录

- 记录版本、构建和发布命令、资源绑定、域名与验收结果；凭据不写入源码或公开文档。
- 区分代码回滚与数据恢复，先评估新旧版本兼容性，避免回退页面时覆盖新增数据。
- 维护域名续期日期，检查证书、访问状态和免费额度用量。
- 有持久化数据时安排受控备份，源码仓库不能代替数据备份。
- 平台规则变化时更新部署说明；内容和功能更新遵循当前项目已有流程。

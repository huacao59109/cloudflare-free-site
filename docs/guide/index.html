GUIDE / 从需求到上线

用 AI 和 Cloudflare 免费方案
搭建一个轻量网站

把页面开发、域名配置和部署维护整理成可重复的流程。下面介绍 Cloudflare Free Site 的用法，以及选择免费方案时需要确认的边界。

huacao59109 · 2026-11-07 · 项目使用指南

为什么整理这个 Skill

我把一次轻量网站的实际开发和部署流程整理成了开源项目 cloudflare-free-site。希望 AI 助手拿到需求后，能沿着明确的步骤完成页面、必要的动态功能、域名配置、发布和验收。

仓库主要由 SKILL.md 和参考文档组成，不包含一套固定成品网站。支持技能目录的工具可以按自己的规范安装；其他助手也可以直接读取这些文件。它不绑定某一家 AI 产品，实际执行能力取决于所用工具及账号授权。

先决定网站需要哪些组件

个人主页、作品集、产品介绍等展示型网站，可以从静态资源开始。需要处理表单或业务逻辑时增加 Worker API；只有确实需要持久保存数据时，再接入 D1。

域名 → Cloudflare DNS / HTTPS
                     ↓
            Cloudflare Workers
            ├─ Static Assets：HTML、CSS、JS、图片
            ├─ Worker API：动态交互，按需添加
            └─ D1：结构化数据，按需添加

用户注册、登录和管理后台也是可选功能。一个没有用户系统需求的展示页，没有必要先建账号库。已有网站则优先复用原工程、稳定的数据 ID 和部署资源。

Workers 是有执行限制的应用运行环境，不是传统 VPS。要运行任意服务器进程、安装现成的传统服务端软件，或执行大量耗时任务，需要另选适合的部署方案。

如何把 Skill 交给 AI 助手

先克隆仓库：

git clone https://github.com/huacao59109/cloudflare-free-site.git

让助手先读取入口文件，再给出具体页面、内容和交互需求。例如：

阅读 cloudflare-free-site/SKILL.md，帮我制作一个产品展示网站。
需要首页、产品介绍和联系方式，风格简洁，适配手机。
先完成本地可运行版本，再按免费域名与 Cloudflare 方案部署。
已有资源优先复用，不开通付费服务。

修改已有网站时，补充数据保留要求：

按 cloudflare-free-site/SKILL.md，为现有网站增加内容管理功能。
需要登录后编辑和保存；保留原有数据与账号，继续使用免费方案。
发布前检查主要操作和权限，提供回滚方法。

参考文档按任务读取：域名与额度、应用与部署、验证与维护。发布账号由使用者本人登录授权，密码和 API 凭据不应写进公开工程。

免费域名与自定义域名怎么接

项目记录了一次 DNSHE .us.ci 免费名称与 Cloudflare 自定义域名成功结合的实践。它是一条当时跑通的路线，申请资格、可用名称以及 Cloudflare 是否接受接管，都需要在操作时核对。

配置顺序是：

  1. 申请允许修改 NS 的免费名称；已有域名可以直接复用。
  2. 在自己的 Cloudflare 账号添加该名称，选择 Free 套餐。
  3. 将域名提供商的 NS 改为 Cloudflare 为当前 Zone 实际分配的两条地址。
  4. 等待 Zone 激活，再在目标 Worker 中添加 Custom Domain。
  5. 确认 HTTPS 证书可用，分别验证页面与动态接口。

不要复制别人案例中的 NS、账号 ID 或数据库 ID。域名注册成功也不等于网站已经可用：NS 委派、DNSSEC 验证、证书和应用路由需要分别检查。Worker Custom Domain 由 Cloudflare 管理对应解析与证书，不能仅把名称 CNAME 到 workers.dev 就视为绑定完成。

截至 2026-11-07，DNSHE 官方说明基础免费名称默认有效期为一年，可在到期前 180 天内免费续期。具体到期时间与续期条件以账号页面为准。参考：DNSHE 官方说明、Worker Custom Domains 文档。

免费额度怎样理解

下面是 2026-11-07 核对的主要额度。它们是规划依据，实施时仍应查看最新官方文档。

资源免费方案主要边界
Workers 静态资源静态资源请求免费；仍有资产文件等限制
Workers 动态请求每天 100,000 次，CPU 时间等限制另计
D1 读取每天 500 万行
D1 写入每天 10 万行
D1 存储账号总计 5 GB；免费单库最大 500 MB

D1 的“行数”不是访问人数。一条查询可能扫描很多行，写入索引和清理旧数据也会消耗额度。让静态内容直接走 Assets，给动态查询使用合适索引，并监测真实用量，比只看每天访问人数更有用。

来源：Workers 定价、D1 定价、D1 限制。

这里的“免费”指满足域名规则及平台额度时，域名和应用托管可以为 0 元。AI 工具、邮件、短信或其他第三方服务的费用需单独核算。

发布以后还要验收什么

除了首页能打开，还要检查手机布局、表单、数据保存以及已有功能。如果有账号系统，应确认匿名和普通用户无法调用管理接口，刷新后会话行为正常，发布新代码不会重灌示例或覆盖现有数据。

国内访问需要在关闭代理的真实宽带和手机流量下测试。曾经某个自定义域名可用，只能说明当时的网络情况；域名后缀不能保证机房所在地、访问速度或未来稳定性。

日常更新应记录发布版本、保留数据库与登录密钥，并准备回滚步骤。源码仓库不能替代数据备份，备份也不应提交到公开仓库。

03 / KNOW THE LIMITS

免费，有明确边界。

符合域名规则且用量未超限时，域名与应用托管可以为 0 元。AI 工具及其他服务的费用另行核算。

01

维护域名有效期仓库记录了 DNSHE 的 .us.ci 实践。申请资格、NS 委派和续期规则需要当次核对。

02

留意使用额度动态请求、CPU、D1 读写和存储都有边界。Workers 是应用托管，不是传统 VPS。

03

实测你的访问环境自定义域名不能保证所有国内线路可用。上线后需要用实际宽带和手机网络检查。

开始前的几个问题

这是一个网站模板吗？

这是建站流程与参考资料。AI 助手根据你的需求创建工程，不提供固定成品页面。

必须使用某一个 AI 工具吗？

不依赖特定助手或编辑器。支持读取文件、编写代码并执行部署的工具可以完成更多步骤；缺少执行能力时可提供工程和操作说明。

可以给已有网站增加功能吗？

可以。流程优先检查现有代码、数据库和部署配置，并保留正常工作的账号、数据与资源。

可以商用或修改这个 Skill 吗？

仓库采用 MIT 许可证，使用和修改时保留许可证声明。托管平台、域名和其他服务的规则仍需分别遵守。
